# 효과음

> 읽는 시점: `vfx-design` 8단계, 그리고 `효과음`만 맡은 Task.

효과음은 화면이 준 정보를 한 번 더 확인해 준다. 소리로만 전하는 중요한 정보는 없어야 한다. 소리를 끈 사용자도 같은 것을 알아야 한다.

## 1. 구하는 순서와 비용

1. 소유자의 자산(브리프나 spec이 가리킨 경로).
2. spec이 정한 수단(생성 서비스, 라이브러리).
3. 수단이 정해지지 않았으면 `ask`로 올린다.

- 비용이나 생성 횟수가 드는 수단은 spec에 허용이 적혀 있을 때만 쓴다.
- 받은 소리의 출처를 리포트의 `## 자산 출처`에 적는다.

## 2. 소리 하나의 구성

| 층 | 역할 |
| --- | --- |
| 어택 | 첫 순간의 날카로운 소리. 화면과 맞는 것은 이 층이다 |
| 몸통 | 소리의 정체(무엇이 닿았나) |
| 꾸밈 | 반짝임, 질감 |
| 저음 | 무게감. 작은 스피커에서는 들리지 않으므로 여기에 뜻을 싣지 않는다 |
| 꼬리 | 울림과 여운 |

- 중요한 소리의 핵심은 1~4 kHz에 둔다. 노트북과 폰 스피커에서 살아남는 대역이다.
- 음이 있는 소리는 조를 맞춘다. 성공과 획득은 밝은 음계, 진행은 한 음씩 올라가게 한다.
- UI 소리에는 울림을 넣지 않는다.
- 세계 안의 소리는 모노로 만든다. 위치는 런타임이 정한다. 좌우 위치를 파일에 구워 넣지 않는다.

## 3. 변형

| 종류 | 변형 수 |
| --- | --- |
| 발소리 | 바닥 종류마다 4~6개 |
| 타격, 맞닿음 | 재질마다 3~5개 |
| 그 밖의 반복되는 소리 | 3~5개 |

- 재생할 때 높낮이 ±2~5%, 음량 ±1~3 dB를 무작위로 준다. 바로 앞에 튼 변형은 다시 고르지 않는다.
- 이 규칙을 효과음 표에 적어 넘긴다. 구현은 개발 쪽이 한다.

## 4. 파일

| 항목 | 기준 |
| --- | --- |
| 형식 | 규약이 정한 것. 없으면 Ogg(Vorbis)나 WebM(Opus)과, 대체용 MP3나 M4A |
| 채널과 샘플 | 짧은 효과음은 모노, 44.1 또는 48 kHz |
| 시작 | 앞의 무음을 잘라 낸다. 무음은 입력이 늦은 것처럼 느껴진다 |
| 끝 | 짧게 줄어들며 끝낸다(수 ms~50 ms). 뚝 끊기면 딱 소리가 난다 |
| 반복 재생 | MP3는 이음매에 틈이 생긴다. 반복하는 소리는 Ogg나 Opus로 만든다 |
| 길이 | 즉각 반응은 짧게(수백 ms 안). 명세의 길이와 맞춘다 |
| 이름 | `<이벤트>_<NN>.<확장자>`. 이벤트 이름은 큐 표의 `sound`와 같다 |

파일을 넘기기 전에 확인한다: 0바이트가 아니다, 길이가 명세와 같다, 재생된다(오류 응답이 파일로 저장된 것이 아니다).

## 5. 음량과 우선순위

| 항목 | 출발값 |
| --- | --- |
| 일반 효과음 | 0.2~0.3 |
| 중요한 사건 | 0.4~0.5 |
| 배경 반복음 | 0.15 |
| 한 번의 큰 타격 | 최대 0.75 |
| 작은 소리와 큰 타격의 차이 | 12~18 dB |
| 같은 효과음을 다시 트는 최소 간격 | 50 ms. 눌림 소리는 110 ms에 한 번 |
| 동시에 나는 소리의 상한 | 모바일 24, 데스크톱 32~64 |

우선순위(상한을 넘으면 낮은 것부터 뺀다): 내 행동의 피드백 → 나와 관련된 다른 사용자의 행동 → 그 밖의 효과 → 배경음. 뺄 때는 가장 작거나, 멀거나, 오래된 것을 뺀다.

- 25% 음량에서 들어 본다. 핵심이 사라지면 대역을 고친다.
- 여러 사용자가 한곳에서 같은 행동을 하면 같은 소리가 겹친다. 효과음 표의 최소 간격과 상한이 이것을 막는다.

## 6. 런타임이 지켜야 할 것 (넘길 메모)

구현은 개발 쪽의 일이지만, 효과음이 제대로 들리려면 아래가 필요하다. 리포트에 요청으로 적는다.

- 소리는 사용자가 처음 화면을 누르거나 클릭한 뒤에만 난다. 브라우저가 그 전의 재생을 막는다.
- 효과음은 미리 받아서 풀어 둔다. 처음 틀 때 풀면 그 순간 화면이 멈칫한다.
- 음량은 한 번에 바꾸지 않고 짧게 이어 바꾼다. 한 번에 바꾸면 딱 소리가 난다.
- 탭이 숨으면 소리를 멈추고, 돌아오면 이어 간다.
- 무음 설정과 소리 끄기 선택을 존중한다. 억지로 틀지 않는다.
- 설정 화면에 전체, 음악, 효과음 음량과 끄기가 있어야 한다.

## 7. 흔한 실수

| 실수 | 결과 |
| --- | --- |
| 모든 바닥에서 같은 발소리 | 세계가 한 가지 재질로 느껴진다 |
| 변형 없이 한 파일 반복 | 기계 소리처럼 들린다 |
| 시작 무음을 남김 | 반응이 느리다고 느낀다 |
| 저음에 뜻을 실음 | 폰 스피커에서 사라진다 |
| 중요한 정보를 소리로만 전달 | 소리를 끈 사용자는 모른다 |
| 화면의 원인 없이 소리를 넣음 | 잡음이 된다 |
| 멈춘 프레임에 소리를 맞춤 | 늦게 들린다 |

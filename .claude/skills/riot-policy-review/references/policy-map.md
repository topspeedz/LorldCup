# Riot 공개 정책의 지도와 출발 점검표

> 읽는 시점: `riot-policy-review` 1단계에서 기준 문서가 없을 때, `legal-baseline`으로 기준 문서를 처음 쓸 때, 어느 문서를 열어야 하는지 찾을 때.

**이 문서는 출발점이다. 정본이 아니다.** 아래 내용은 2026-11-12에 웹 도구로 원문을 읽어 정리한 것이고, 그 도구는 요약 모델을 거친다. 정책은 바뀐다. 검토할 때마다 원문을 다시 열어 문장과 개정일을 확인하고, 확인한 것을 기준 문서 `docs/live/legal-review/legal-baseline.md`에 확인일과 함께 옮긴다. 기준 문서에 값이 생기면 그 값을 쓴다.

**읽지 못했거나 찾지 못한 것.** 아래는 비어 있다. 해당하는 일을 하게 되면 먼저 원문을 찾아 읽는다.

- API 약관, 개인정보 고지, Riot 계정 로그인 연동의 정책
- 대회 영상의 공동 중계와 다시 보기, 하이라이트의 현행 규칙
- 한국에만 적용되는 대회 지침과 국내 리그의 콘텐츠 규칙
- 공개된 브랜드 지침. 보도 자료 페이지에는 사용 조건이 없었다
- 개발자 정책에서 보도 자료의 로고 사용을 허용하는 조건(문장이 잘려 확인하지 못함)
- 커뮤니티 대회 지침의 문장. 요약만 받았다. 문장 단위로 다시 확인해야 한다

## 2. 문서별로 본 것

조항의 위치를 찾는 데 쓴다. 문장은 원문에서 다시 확인한다.

### 팬 제작물 정책

| 주제 | 본 것 | 위치 |
| --- | --- | --- |
| 허락의 성격 | 개인적이고, 양도할 수 없고, 언제든 거둘 수 있는, 비상업적 커뮤니티 이용을 위한 제한된 허락 | 1절 |
| 상업적 프로젝트 | 만들 수 없다. 사업체나 법인이 관여하는 것이 포함된다. 한국어판은 일부라도 크라우드펀딩으로 자금을 마련한 프로젝트를 포함한다고 적는다. 결제 벽도 안 된다(요약) | 2절 |
| 수익의 예외 | 적절한 광고로 수동적인 수익은 낼 수 있다. 무엇이 부적절한 광고인지는 Riot이 정한다. 개인 후원과 구독은 게임을 생방송할 때의 예외다 | 2절 |
| API 프로젝트의 예외 | API 약관과 정책을 지키고 그 프로젝트에 발급된 유효한 키가 있으면 상업적 API 프로젝트가 가능하다 | 2절 |
| 게임과 앱 | 게임과 앱에서 Riot의 지식재산을 쓰는 것을 금지한다. 한국어판은 애플과 구글의 앱 장터에 올리는 것을 허용하지 않는다는 문장이 더 있다 | 3절 |
| 기존 콘텐츠 | 대회 경기나 다른 사람의 영상 같은 기존 콘텐츠를 그대로 쓰거나 가벼운 해설만 붙이지 말라고 한다 | 4절 |
| 로고와 상표 | 서면 허락 없이 프로젝트 어디에도 Riot의 로고와 상표를 쓸 수 없다. 한국어판은 웹사이트, 광고물, 영상, 그 밖의 게시물을 든다 | 5절 |
| 이름 | Riot의 상표가 든 도메인과 계정을 등록할 수 없다. 상표와 지식재산의 이름을 검색 키워드나 태그로 쓰지 말라고 한다 | 5절 근처 |
| 제3자의 지식재산 | 그 권리자의 허락 없이 쓸 수 없다 | 5절 근처 |
| 고지문 | 반드시 표시한다. 아래 3절 | 6절 |
| Riot의 권리 | 언제든 사용을 거절하고 프로젝트를 중단시킬 수 있다. 키를 거두면 즉시 내려야 한다. 팬 프로젝트를 대가 없이 소개할 수 있다(요약) | 여러 곳, 7절 |
| 음악 | 언급이 없다 | - |

### 개발자 포털 일반 정책 (Riot API를 쓸 때)

| 주제 | 본 것 |
| --- | --- |
| 등록 | 모든 제품은 개발자 포털에 등록하고 Riot의 심사를 받는다. 기능을 더하거나 바꿀 때도 심사한다(요약) |
| 수익 | 등록되고 승인된 제품은 수익을 낼 수 있다. 플레이어가 무료로 쓸 수 있는 등급이 있어야 한다. 유료 부분에는 변형적인 내용이 있어야 한다(요약) |
| 금지 | 베팅과 도박 기능. 암호화폐와 블록체인. 스타일이나 기능이 Riot의 게임과 제품을 닮은 것. Riot의 지식재산으로 게임을 만드는 것. 공식 실력 순위를 대신하는 계산. 보이는 정보로는 알 수 없는 플레이어를 식별하는 것 |
| 표시 | Riot이 승인하거나 후원하지 않으며 Riot의 견해를 반영하지 않는다는 문구를 플레이어가 쉽게 보는 곳에 둔다. 팬 제작물 정책의 고지문과는 다른 문장이다 |
| 키 | 키를 코드에 넣지 않는다. 키 하나에 제품 하나. 암호화된 연결을 쓴다 |
| 자산 | 정적 데이터 묶음과 보도 자료를 쓴다. 보도 자료의 로고와 상표는 정해진 경우로 제한된다(조건 확인 못 함) |
| 대회 | 참가비의 70% 이상을 상금으로, 참가자 20명 이상, 도박 금지 |
| 제재 | API 사용의 정지나 취소, 법적 조치 |

### 리그 오브 레전드 게임 정책

- 승인되는 예와 승인되지 않는 예의 목록이 있다. 플레이어가 미리 알 수 없는 게임 세션의 정보를 주는 것은 승인되지 않는다.
- 대회 결과나 선수 정보 같은 e스포츠 데이터는 언급이 없다.

### 이용약관

- Riot과 그 허락자가 서비스의 모든 권리를 갖는다. 캐릭터, 그림, 소리가 포함된다(요약).
- 명시적으로 허락된 경우가 아니면 게임 콘텐츠에 바탕을 둔 저작물을 만들 수 없다. 팬 제작물 정책이 그 허락의 근거다.
- 저작권과 상표의 고지를 지우거나 바꾸지 말라고 한다. 서면 동의 없이 사업 목적으로 쓰지 말라고 한다.

### 커뮤니티 대회 지침 (전부 요약, 문장 확인 필요)

- Riot과 공식 대회의 로고를 홍보에 쓰지 못한다. 세계 대회와 지역 리그 같은 공식 브랜드의 이름을 쓰지 못한다. 공식 대회로 보이게 하지 못한다.
- 후원을 받을 수 없는 범주가 있다(도박, 암호화폐 등).
- Riot은 재량으로 개입하고 중단시킬 수 있다.

## 5. 정책이 답하지 않는 것 (2026-11-12 기준)

아래는 결론을 내지 않는다. 리포트의 `## 판단 필요`에 올리고, 기준 문서의 미결 절에 지금의 처리를 적는다.

| 쟁점 | 왜 갈리는가 |
| --- | --- |
| 웹 3D 공간이 "게임과 앱"에 드는가 | 팬 정책은 게임과 앱에서의 사용을 금지하지만 그 말을 정의하지 않는다. 캐릭터가 돌아다니고 상호작용하는 웹 공간이 어디에 드는지 답이 없다 |
| 로고의 사용 | 팬 정책은 전면 금지하고, 개발자 정책은 보도 자료의 로고를 제한된 경우에 허용한다. API 제품만의 예외인지 알 수 없다 |
| 수익의 범위 | 팬 정책은 광고만 예외로 두고, 개발자 정책은 등록된 제품에 더 넓게 허용한다. API를 쓰면 넓어지는지 확인이 필요하다 |
| 음악과 소리 | 팬 정책에 언급이 없다. 이용약관은 소리를 게임 콘텐츠에 넣는다 |
| 대회 결과와 선수 정보 같은 e스포츠 데이터 | 개발자 정책과 게임 정책에 언급이 없다 |
| 대회 영상의 공동 중계와 하이라이트 | 현행 공식 규칙을 찾지 못했다 |
| 문서 사이의 시차 | 팬 정책의 개정일은 2018년이고 다른 문서는 2024~2026년이다 |

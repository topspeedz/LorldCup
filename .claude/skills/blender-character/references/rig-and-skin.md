# 리깅과 스키닝

> 읽는 시점: `blender-character` 7단계. 캐릭터 모델의 관절 부위를 만들 때(6단계)도 1절을 읽는다.

## 1. 변형되는 곳의 토폴로지

- 어깨, 팔꿈치, 손목, 고관절, 무릎, 발목, 손가락 마디 둘레에 에지 루프를 2~3개 둔다. 루프는 관절이 접히는 축에 수직으로 돈다.
- 접히는 안쪽보다 바깥쪽에 면을 더 둔다. 바깥쪽이 늘어나기 때문이다.
- 변형되는 곳은 사각형 면으로 고르게 만든다. 긴 삼각형과 한 점에 몰린 면은 접힐 때 찌그러진다.
- 어깨를 뚜껑 막은 원통으로, 손가락을 서로 뚫고 지나가는 원기둥으로 만들지 않는다. 겉으로 멀쩡해 보여도 움직이면 무너진다.

## 2. 뼈대

- 이름과 계층은 자산 연동 규약의 목록을 그대로 쓴다. 규약이 없으면 아래를 쓰고 "출발값 사용"이라고 적는다.

  ```text
  root → hips → spine → chest → neck → head
  chest → shoulder.L → upper_arm.L → forearm.L → hand.L   (오른쪽은 .R)
  hips  → thigh.L → shin.L → foot.L → toe.L               (오른쪽은 .R)
  ```

- **같은 뼈 이름, 같은 기본 포즈, 같은 비례여야 캐릭터끼리 클립을 함께 쓴다.** 비례가 다르면 같은 클립에서 발이 미끄러진다. 그래서 공통 뼈대와 공통 비례가 캐릭터 일관성의 기술적 바탕이다.
- 루트 뼈는 원점(0, 0, 0)의 바닥에 두고 회전을 주지 않는다.
- 뼈는 스케일하지 않는다. 크기를 바꿔야 하면 루트에 고른 스케일만 준다.
- 소품이 붙을 자리(손, 등, 머리)에는 부착용 뼈나 빈 오브젝트를 두고 이름을 규약대로 붙인다. 소품 자체는 만들지 않는다.
- 뼈 수는 예산 안에서 정한다. 모바일은 30~50개가 출발값이다. 손가락을 마디마다 나눌지, 손 전체를 뼈 하나로 둘지는 화면에서 손이 얼마나 크게 보이는지로 정한다.

## 3. 비틀림

- 팔뚝을 뼈 하나로 두면 손목을 돌릴 때 사탕 껍질처럼 꼬인다. 팔꿈치와 손목 사이에 비틀림 뼈를 둔다. 둘이면 33%와 66% 자리에 둔다.
- 어깨는 쇄골 뼈를 두고, 위팔 회전의 일부(약 30%)를 받는 보조 뼈를 둔다.
- 뼈 수 예산이 빠듯하면 비틀림 뼈를 하나로 줄이거나 빼고, 대신 애니메이션에서 손목 회전 범위를 좁힌다. 어느 쪽을 골랐는지 리포트에 적는다.

## 4. 바인드 전

1. 메시 오브젝트의 변환을 정리한다: 스케일 1, 회전 0.
2. 아마추어의 변환을 적용한다.
3. 기본 포즈가 규약의 포즈(T 또는 A)인지 본다.

나쁜 바인드 포즈는 가중치를 아무리 칠해도 고쳐지지 않는다. 바인드한 뒤에는 변환을 전부 적용하지 않는다.

## 5. 가중치

| 규칙 | 이유 |
| --- | --- |
| 정점 하나에 영향을 주는 뼈는 4개까지 | glTF의 기본 스킨 데이터가 4개다. 넘는 것은 내보낼 때 잘려 찢어진다 |
| 0.01보다 작은 가중치는 지우고 주된 뼈로 돌린다 | 같은 이유 |
| 가중치 합은 1로 정규화 | 합이 다르면 메시가 떠오르거나 꺼진다 |
| 가중치가 없는 정점 0 | 그 정점은 제자리에 남아 이음새가 찢어진다 |

- `get_scene_info(fields=["weights"])`로 "어떤 변형 뼈도 움직이지 않는 정점"과 "정점 그룹이 없는 변형 뼈"를 본다.
- 가중치는 포즈를 잡아 놓고 본다. 중립 포즈에서는 틀린 가중치가 보이지 않는다.

## 6. IK와 제한

- IK와 컨스트레인트는 만들 때 쓰는 도구다. 내보내기 전에 키로 굽는다.
- 폴 벡터는 굽힘 평면 위에, 팔다리 길이의 1~2배 거리에 둔다.
- Blender에서 건 관절 각도 제한은 넘어가지 않는다. 애니메이션을 제한 안에서 만든다.

## 7. 셰이프 키 (표정)

- `Basis`가 먼저 있어야 한다.
- 셰이프 키는 정점 번호로 저장된다. 만든 뒤에는 바탕 메시의 토폴로지를 바꾸지 않는다.
- 키마다 100%로 올려 본다. 서로 겹치는 키(웃음 + 눈 감기)는 함께 올려 본다.
- 표정의 기본 집합은 기쁨, 슬픔, 분노, 공포, 놀람, 경멸이다. 눈, 눈썹, 입의 조합으로 만든다.
- 셰이프 키는 정점 데이터를 통째로 더한다. 메모리와 내려받는 크기가 는다. 화면에서 얼굴이 읽히는 거리의 캐릭터에만, 필요한 키만 넣는다.

## 8. 합격 포즈

계약의 포즈마다 앞, 옆, 뒤, 변형되는 곳 근접을 렌더해 열어 본다.

| 포즈 | 볼 것 |
| --- | --- |
| 중립 | 좌우 대칭, 손발이 바닥과 맞닿는 자리 |
| 팔꿈치와 무릎 끝까지 굽힘 | 안쪽이 파고들지 않는가, 바깥쪽 부피가 꺼지지 않는가 |
| 팔을 위, 앞, 옆으로 뻗기 | 어깨가 꺼지거나 겨드랑이가 찢어지지 않는가 |
| 몸통과 손목 비틀기 | 사탕 껍질처럼 꼬이지 않는가 |
| 쪼그려 앉기 | 고관절이 무너지지 않는가, 옷이 뚫리지 않는가 |
| 걷는 중 디딤 | 발바닥이 바닥에 붙는가 |
| 표정 | 눈꺼풀과 입술이 서로 파고들지 않는가 |

원치 않는 스케일과 비스듬히 밀림(전단)이 없는지 수치로도 본다.

## 9. 축과 내보내기

- 캐릭터의 정면은 Blender에서 −Y다. glTF에서는 +Z가 앞이 된다. 처음 한 번은 방향을 적은 시험 상자를 내보내 확인한다.
- 머리, 가슴, 발, 루트가 움직이는 방향을 함께 비교해 축을 정한다. "+Y를 본다"고 가정하지 않는다.
- 내보낸 뒤 임시 컬렉션에 다시 가져와 계층, 가중치, 재질, 액션, 프레임 범위, 스케일, 방향을 원본과 비교한다.

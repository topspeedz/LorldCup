# 캐릭터 애니메이션

> 읽는 시점: `blender-character` 8단계(애니메이션)와 9단계(동작 상태 점검). 이펙트 담당이 캐릭터 클립의 큐 프레임을 읽을 때도 6절을 본다.

자연스러움은 감이 아니라 몇 가지 물리적 사실에서 나온다. 무게가 있는 것은 갑자기 출발하거나 멈추지 못한다. 몸의 부분은 한꺼번에 움직이지 않는다. 관절 끝은 직선이 아니라 호를 그린다.

## 1. 모션 성격은 하나다

모션 성격은 아트 디렉션 문서가 정한 하나를 모든 캐릭터에 쓴다. 캐릭터마다 다른 것은 성격 안에서의 크기와 리듬이다.

| 성격 | 과장 정도 |
| --- | --- |
| 장난스러움 | 15~25% |
| 활기참 | 20~30% |
| 단정함 | 0~5% |
| 고급스러움 | 0% |

커브와 감쇠 값은 이름 붙인 몇 가지만 쓴다. 클립마다 즉석에서 만든 커브가 스타일을 무너뜨린다.

## 2. 원칙과 수치

시간은 밀리초로 적는다. 프레임 수는 클립의 fps로 환산한다(fps는 규약이 정하고, 없으면 30).

| 원칙 | 적용 | 수치 |
| --- | --- | --- |
| 예비 동작 | 큰 동작 앞에 반대 방향으로 조금 움직인다 | 이동 거리의 2~4%, 100~170 ms. 모든 동작에 넣으면 만화처럼 된다 |
| 늘어남과 눌림 | 접촉 순간 눌리고, 빠를 때 늘어난다. 부피는 지킨다 | 약 1.2 / 0.8. 뼈 스케일이 아니라 포즈로 만든다 |
| 후속 동작과 겹침 | 몸통이 멈춘 뒤 팔, 머리카락, 옷이 늦게 따라와 멈춘다 | 자식 부위 50~150 ms 지연, 끝부분은 100~200 ms 늦게 멈춤 |
| 부수 동작 | 주된 동작을 돕는 작은 움직임(걷는 중 고개, 손짓) | 주된 동작 크기의 30~50%, 50~100 ms 뒤 |
| 가속과 감속 | 공간을 이동하는 키 사이를 직선 보간으로 두지 않는다 | 직선 보간은 일정한 회전에만 쓴다 |
| 호 | 손, 발, 머리 끝의 궤적이 호를 그린다 | 모션 패스로 확인한다 |
| 타이밍 | 동작마다 길이가 달라야 한다 | 가장 긴 동작이 가장 짧은 동작의 3배 이상 |
| 무게 | 무게는 출발과 정지에서 드러난다 | 접촉 프레임에서 아직 움직이고 있어야 한다(가속하며 닿는다) |
| 반동 | 실제로 바닥이나 고정된 것에 닿았을 때만 넘쳤다 돌아온다 | 그 밖에는 출렁임 없이 멈춘다 |
| 포즈에서 포즈로 | 핵심 포즈를 먼저 잡고 사이를 채운다 | 핵심 포즈만 넘겨 봐도 동작이 읽혀야 한다 |
| 보여 주기 | 한 번에 주된 동작 하나 | 실루엣으로 읽히는 포즈를 고른다 |

**생성된 티가 나는 신호.** 모든 곳이 출렁인다. 모든 동작의 길이가 같다. 이동이 직선으로 미끄러진다. 동작마다 예비 동작이 붙는다. 넷 중 하나라도 보이면 고친다.

## 3. 걷기와 달리기

- 한 걸음의 핵심 포즈는 넷이다: 디딤(앞발 뒤꿈치가 닿음) → 내려감(무게가 실려 가장 낮음) → 지나감(뒷발이 디딘 발을 지남) → 올라감(밀어 올려 가장 높음). 반대 발로 한 번 더 하면 한 사이클이다.
- 골반은 위아래로 오르내리고 디딘 발 쪽으로 기운다. 어깨는 골반과 반대로 돈다. 팔은 반대쪽 다리와 함께 나간다.
- 디딘 발은 디딤 구간 동안 바닥에 붙어 있다. 제자리 클립에서는 발이 **일정한 속도로** 뒤로 밀려야 한다.
- **기준 이동 속도를 넘긴다.** 한 사이클에 나아가는 거리 ÷ 한 사이클의 시간(m/s). 런타임의 이동 속도가 이 값과 맞아야 발이 미끄러지지 않는다. 클립 표의 `기준 이동 속도` 칸에 적는다.
- 걷기와 달리기는 같은 발이 같은 시점(사이클의 같은 비율)에 닿게 맞춘다. 런타임이 두 클립을 섞을 때 다리가 엇갈리지 않는다.

## 4. 루프와 전환

- 루프 클립은 첫 키와 끝 키의 포즈가 같다. 같은 포즈가 두 번 재생되면 멈칫하므로 끝 프레임의 처리를 규약대로 한다(끝 프레임을 빼거나, 런타임이 끝 프레임을 건너뛴다).
- 이음매에서 커브의 기울기가 이어져야 한다. 포즈가 같아도 속도가 다르면 덜컥한다.
- 런타임은 클립 사이를 0.2~0.4초로 섞는다. 그래서 클립의 시작 포즈를 공통 기준 포즈 근처에 두면 어떤 클립에서 넘어와도 튀지 않는다.
- 제자리 클립과 코드 이동이 기본이다. 루트가 이동하는 클립이 필요하면 이름으로 구분하고 규약에 맞춘다.

## 5. 개성

- 캐릭터 시트의 동작 기둥(걷는 리듬, 버릇 동작, 하지 않는 동작)을 클립마다 지킨다.
- 같은 인사도 활발한 캐릭터는 팔 전체로 크게, 차분한 캐릭터는 손목으로 작게 한다. 뼈대와 클립 이름은 같고 포즈의 크기와 타이밍이 다르다.
- 공통 클립(걷기, 달리기)은 함께 쓰고, 개성은 대기 동작과 감정 표현 클립에서 낸다. 그래야 클립 수와 일관성을 함께 지킨다.

## 6. 큐 프레임

이펙트, 효과음, 런타임이 맞출 순간을 클립 표에 적는다.

| 큐 | 어느 프레임인가 |
| --- | --- |
| 발 디딤 | 발이 바닥에 닿는 프레임 |
| 접촉, 타격 | 손이나 물체가 닿는 프레임. 멈춘 프레임이 아니다 |
| 정점 | 동작이 가장 크게 펼쳐진 프레임 |
| 예비 시작 | 예비 동작이 시작되는 프레임 |

클립의 타이밍을 바꾸면 큐 프레임도 다시 적는다. 이펙트와 효과음이 이 표에 묶여 있다.

## 7. 수치로 점검하기

처음, 중간, 접촉, 공중, 극단 프레임을 뽑아 표로 만든다.

| 항목 | 재는 법 | 기준 |
| --- | --- | --- |
| 지면 관통 | 발과 손의 가장 낮은 점의 높이 | 바닥 아래로 2 cm 이내 |
| 발 미끄러짐 | 디딤 구간의 첫 프레임과 끝 프레임에서 발 뼈의 월드 위치 차이(제자리 클립은 기준 이동 속도를 빼고) | 눈에 띄지 않는 크기. 수치를 적는다 |
| 스케일 변화 | 바운딩 박스 크기의 변화 | 5% 이내 |
| 루트 방향 | 프레임 사이 루트의 회전 차이 | 30° 이내 |
| 루프 이음매 | 첫 프레임과 끝 프레임의 뼈 회전 차이 | 0 또는 허용치 |
| 다리 엇갈림, 비틀림 | 좌우 발의 좌우 위치가 뒤바뀌는가, 무릎이 발끝과 다른 쪽을 보는가 | 없음 |

## 8. Blender에서 걸리는 곳

- 포즈 뼈의 회전은 기본이 쿼터니언이다. 오일러로 키를 잡으려면 `rotation_mode`를 먼저 바꾼다.
- 액션의 F-커브에 접근하는 API는 Blender 버전에 따라 다르다. 액션을 넣었는데 움직이지 않으면 액션 슬롯 지정을 확인한다. 쓰기 전에 `dir()`로 확인한다.
- 내보내기 전에 굽는다: `bpy.ops.nla.bake`(보이는 대로 키 잡기, 컨스트레인트 지우기, 포즈 대상). 다른 프로그램은 컨스트레인트, NLA, 드라이버를 읽지 못한다.
- 활성 액션은 NLA 트랙을 덮는다. 내보낼 때 활성 액션을 비우거나 내보내기 방식을 확인한다.
- 굽기 전의 `.blend`를 남긴다. 구운 뒤에는 고치기 어렵다.

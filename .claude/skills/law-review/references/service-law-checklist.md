# 서비스 운영 관련 법 점검표

> 읽는 시점: `law-review` 4단계에서 개인정보, 서비스 문서, 이용자의 콘텐츠와 대화, 나이, 거래를 검토할 때.

**출발점이다. 정본이 아니다.** 조문 번호는 참고 자료에서 옮긴 것이라 검토할 때 원문(국가법령정보센터)에서 확인해 확인일과 함께 적는다. 수치(보관 기간 같은 것)도 원문에서 다시 확인한다. 기준 문서에 값이 생기면 그 값을 쓴다.

어느 절이 걸리는지는 서비스의 사실이 가른다. 절마다 "걸리는 때"를 먼저 본다. 걸리지 않으면 "해당 없음"과 그 이유를 적는다.

## 1. 개인정보

**걸리는 때:** 계정, 닉네임과 식별자, 채팅, 접속 기록, 분석 도구, 광고 식별자 가운데 하나라도 다룬다.

가장 센 통제는 덜 모으는 것이다. 필요 없는 정보는 지킬 필요도 없다. 모으는 항목마다 "없으면 무엇이 안 되는가"를 먼저 묻는다.

| 볼 것 | 근거(개인정보 보호법. 조문은 원문에서 확인) |
| --- | --- |
| 모으기 전에 항목, 목적, 보관 기간을 알리고 동의를 받는가. 꼭 필요한 것과 골라서 주는 것을 나눴는가 | 수집과 이용(제15조), 최소한의 수집 |
| 밖에 주거나(제3자 제공) 일을 맡기는(위탁) 곳이 있는가. 따로 알렸는가 | 제3자 제공(제17조), 위탁 |
| 민감한 정보, 고유 식별 정보를 다루는가 | 민감정보(제23조), 고유식별정보(제24조) |
| 홍보에 쓰는 동의를 따로 받는가 | 동의를 받는 방법(제22조) |
| 정보가 국외로 가는가(국외의 서버, 국외의 분석·인증·실시간 통신 서비스) | 국외 이전(제28조의8) |
| 만 14세 미만의 아동을 받는가. 받으면 법정대리인의 동의를 받는 길이 있는가 | 아동의 개인정보 |
| 처리방침을 공개했는가. 실제로 모으는 항목과 맞는가 | 처리방침(제30조) |
| 탈퇴하면 지우는가. 보관 기간이 지나면 지우는가 | 파기 |
| 전송을 암호화하는가. 접근을 막는가. 접속 기록을 남기는가 | 안전 조치. 보관 기간의 수치는 원문에서 확인한다 |

- [ ] 동의 칸을 미리 체크해 두지 않았다. 여러 동의를 하나로 묶지 않았다.
- [ ] 동의를 거두는 것이 동의하는 것만큼 쉽다. 동의한 기록이 남는다.
- [ ] 쿠키와 분석 도구를 꼭 필요한 것, 기능, 분석, 홍보로 나눠 적었다.
- [ ] **코드가 실제로 모으는 항목과 처리방침의 항목이 같다.** 폼, 저장하는 값, 외부로 보내는 값을 코드에서 찾아 대조한다. 가장 흔한 결함이 여기서 나온다.
- [ ] 채팅의 내용을 저장하는가. 저장하면 무엇을, 얼마 동안, 누가 볼 수 있는가.
- [ ] 다른 이용자에게 보이는 정보(닉네임, 위치, 접속 상태)를 이용자가 알고 고를 수 있는가.

**처리방침에 들어가야 하는 것.** 처리하는 목적, 항목, 보관 기간, 제3자 제공, 위탁, 국외 이전, 정보 주체의 권리와 행사 방법, 파기, 안전 조치, 자동으로 모으는 장치(쿠키)의 설치와 거부, 책임자와 문의처, 방침의 변경. 목록은 원문에서 확인한다. 이 역할은 방침을 쓰지 않는다. 빠진 것과 실제와 다른 것을 적는다.

## 2. 이용약관

**걸리는 때:** 약관이 있거나, 계정을 만들게 하거나, 이용자가 무엇을 올리게 한다.

아래 말이 나오면 한쪽에 지나치게 불리한 조항일 수 있다(약관의 규제에 관한 법률). 조항을 찾아 적는다. 불공정한지의 판단은 사람이 한다.

| 찾을 말 | 문제 될 수 있는 것 |
| --- | --- |
| "일체의 책임을 지지 않" | 사업자의 책임을 통째로 없앰 |
| "사전 통지 없이" | 알리지 않고 바꾸거나 끊음 |
| "환불 불가" | 돌려받을 권리를 통째로 없앰 |
| "동의한 것으로 간주" | 가만히 있는 것을 동의로 봄 |
| "임의로 변경", "재량에 따라" | 한쪽이 마음대로 정함 |

- [ ] 이용자가 올린 것의 권리가 누구에게 있는지, 서비스가 어디까지 쓰는지 적혀 있다.
- [ ] 계정을 멈추거나 지우는 기준과 알리는 방법이 적혀 있다.
- [ ] 약관을 바꿀 때 알리는 방법과 기간이 적혀 있다.

## 3. 문서끼리, 문서와 실제

서비스 문서(약관, 처리방침, 고지)는 서로 맞고 실제와 맞아야 한다.

- [ ] 서비스의 이름과 운영자가 문서마다 같다.
- [ ] 모으는 항목이 처리방침, 동의 화면, 코드에서 같다.
- [ ] 시행일이 문서마다 있고 서로 어긋나지 않는다.
- [ ] 같은 것을 가리키는 말이 문서마다 같다.
- [ ] 나이의 기준이 문서마다, 그리고 가입 화면과 같다.
- [ ] 문서가 말하는 기능(탈퇴, 신고, 동의 철회)이 실제로 있다.

## 4. 이용자의 콘텐츠와 대화

**걸리는 때:** 채팅, 닉네임, 이용자가 올리는 그림이나 글이 다른 이용자에게 보인다.

- [ ] 신고하는 길이 화면에 있다. 신고를 받으면 누가, 언제까지, 무엇을 하는지 정해져 있다.
- [ ] 다른 이용자를 막거나 안 보이게 하는 길이 있다.
- [ ] 권리를 침해당했다는 통지를 받는 연락처와, 받았을 때 내리고 올린 사람에게 알리는 절차가 있다. 저작권법은 이런 절차를 갖춘 서비스 제공자의 책임을 줄여 준다. 요건은 원문에서 확인한다.
- [ ] 같은 침해를 되풀이하는 계정을 다루는 기준이 있다.
- [ ] 법이 금지하는 정보(정보통신망 이용촉진 및 정보보호 등에 관한 법률)가 올라왔을 때의 처리가 정해져 있다.
- [ ] 저작권 고지가 있다: 무엇이 누구의 것인가, 이용자가 올린 것의 권리, 침해 신고의 길.

## 5. 나이와 청소년 보호

**걸리는 때:** 나이 제한 없이 누구나 들어온다. 또는 청소년이 주된 이용자다.

- [ ] 이용자의 나이를 어떻게 다루는지 정해져 있다(받지 않는다, 묻는다, 확인한다).
- [ ] 만 14세 미만을 받으면 1절의 아동 항목이 걸린다. 받지 않으면 가입에서 어떻게 막는지 적혀 있다.
- [ ] 청소년에게 해로울 수 있는 내용(광고 포함)이 드러날 길이 있는가.
- 근거가 되는 법: 청소년 보호법, 정보통신망법의 청소년 보호 조항. 조문은 원문에서 확인한다.

## 6. 게임으로 볼 수 있는가

**걸리는 때:** 점수, 승패, 보상, 진행 목표, 우연으로 얻는 것, 돈으로 바꿀 수 있는 것이 있다.

- [ ] 게임으로 볼 수 있는 요소를 기능 목록에 표시했다.
- [ ] 우연에 따라 얻는 보상, 경품, 돈으로 바꿀 수 있는 재화가 있는가.
- 게임물에 해당하면 등급 분류 같은 의무가 따른다(게임산업진흥에 관한 법률). 가상 공간 서비스가 게임물인지는 요소에 따라 갈리는 문제다. **결론을 내지 않는다.** 요소를 사실로 정리해 `## 판단 필요`에 올린다.
- 권리자의 정책도 게임인지를 따로 묻는다. 그 대조는 `riot-policy-reviewer`가 한다. 같은 사실 표를 함께 쓴다.

## 7. 돈과 광고

**걸리는 때:** 결제, 유료 재화, 후원, 광고 가운데 하나라도 있다. 없으면 이 절 전체가 "해당 없음"이다.

- [ ] 광고와 후원을 광고와 후원이라고 표시한다(표시·광고의 공정화에 관한 법률).
- [ ] 돈을 받고 무엇을 주면: 사업자의 정보 표시, 청약의 철회와 환불의 안내(전자상거래 등에서의 소비자보호에 관한 법률).
- [ ] 홍보하는 글을 이용자에게 보내면: 받겠다는 동의, 보내는 사람의 표시, 받지 않는 길(정보통신망법).
- 수익이 붙으면 다른 절의 판정도 바뀐다. 비영리 조건의 자산(지식재산 점검표 2절), 권리자의 정책, 사람의 이름과 모습(6절)을 다시 본다.

## 8. 사실이 바뀌면 다시 볼 것

| 바뀐 것 | 다시 볼 절 |
| --- | --- |
| 로그인이나 계정이 생김 | 1, 2, 3, 5 |
| 채팅이나 올리기 기능이 생김 | 1, 4 |
| 외부 서비스(분석, 인증, 실시간 통신)가 더해짐 | 1의 위탁과 국외 이전 |
| 결제, 후원, 광고가 생김 | 7, 그리고 지식재산 점검표 전체 |
| 점수, 보상, 경쟁이 생김 | 6 |
| 나이의 기준이 바뀜 | 1, 5 |

# Barclays WORLDS 2026 · 웹 GLB

2026-11-12 내보내기. GEN.G 금색 / BLG 청록·분홍 무대, 팀당 5석, 관중 동작과 환호음, Blender에서 구운 고정 조명이 포함된 웹 실행 패키지입니다.

## 실행과 게시

- 압축을 푼 뒤 상위 폴더의 `start.cmd`를 실행합니다. Python이 설치된 Windows에서 `http://127.0.0.1:8766/`으로 열립니다.
- 직접 실행하려면 이 `web` 폴더에서 `python -m http.server 8766 --bind 127.0.0.1`을 실행하고 위 주소를 엽니다.
- 웹에 게시할 때는 **`web/` 안의 모든 파일과 `vendor/`, `lightmaps/` 폴더**를 같은 상대 경로로 정적 HTTPS 호스팅에 올립니다. `index.html`을 파일 탐색기에서 직접 여는 `file://` 방식은 사용하지 않습니다.
- **관중 소리 켜기**를 누르면 30초 환호음이 동작과 함께 반복됩니다. 브라우저의 오디오 정책 때문에 첫 재생에는 버튼 클릭이 필요합니다.
- WASD 이동, 마우스 시점, **Space 점프**, Shift 달리기, Esc 메뉴, 위치 이동 버튼을 사용할 수 있습니다.

스페이스바를 한 번 누르면 지면에서 점프합니다. 공중 연속 점프와 키를 누른 채 자동 재점프는 지원하지 않으며, 착지 후 다시 누르면 점프합니다. 이동 중에도 점프할 수 있고, 다른 참가자에게도 높이가 전달됩니다.

## 전달 파일

| 파일 | 용도 |
|---|---|
| `arena.glb` | 경기장·외관과 완성된 커피·스낵 매장 21개 구역, 표면 이미지 내장 |
| `lightmaps/` | 7개 RGBM 라이트맵, 커피숍 조명 포함 |
| `baked-lighting.js`, `lighting.js`, `lighting-config.json` | 고정 조명 적용, 움직이는 대상의 실시간 조명, 광선과 색상 처리 |
| `*-reflections.hdr`, `world-background.png` | Blender에서 렌더한 무대·복도·외부 반사와 원본 배경 |
| `crowd-motion.js` | 관중의 관절 속성을 읽어 GPU에서 앉기·응원·박수·응원봉 동작 재생 |
| `crowd-performance.mp3` | 30초 관중음, 12초와 23.5초 환호 구간 |
| `main.js`, `index.html` | 이동·충돌·조명·음향 버튼을 연결한 Three.js 뷰어 |
| `vendor/` | Three.js r170, GLTFLoader, RGBELoader, Draco WASM 디코더 및 기존 PeerJS 의존성 |
| `audio-sources.md` | 음원 출처와 제공처 라이선스 기록 |

**GLB 자체에는 표준 애니메이션 클립이 없습니다.** Blender Geometry Nodes 동작을 복제한 `crowd-motion.js`와 별도 MP3를 함께 사용해야 웹에서 관중 동작과 소리가 재생됩니다. 일반 GLB 뷰어에 모델만 넣으면 관중은 정지 상태로 표시됩니다.

GLB는 `KHR_draco_mesh_compression`을 사용합니다. 다른 Three.js 프로젝트에서 불러올 때도 DRACOLoader를 연결하고, 모델 로드 후 `createCrowdMotion(gltf.scene, ctx)`를 호출한 뒤(`ctx`는 `camera`, `config`, `events`를 담은 객체로 `main.js`가 만듭니다) 렌더 루프에서 반환 객체의 `update(performance.now())`를 실행해야 합니다. 실행 예시는 `main.js`에 있습니다. 사용자 정의 `_CM_*` 정점 속성이 보존되어야 합니다.

**고정 조명도 GLB만으로 재생되지 않습니다.** 함께 제공한 `createHybridLighting(gltf.scene, renderer, scene)`과 외부 라이트맵·HDR·설정 파일이 필요합니다. GLB의 `bakedLighting` 메타데이터와 `_LIGHTMAP_UV` 정점 속성을 보존해야 합니다. 일반 GLB 뷰어에는 이 사용자 정의 조명 처리가 없습니다.

## 조명 처리

- 건물·바닥·무대·좌석·매장의 고정된 빛과 그림자는 Cycles의 Diffuse Direct+Indirect를 색상 제외로 구워 적용합니다. 실시간 조명이 여기에 다시 더해지지 않습니다.
- 움직이는 관중과 캐릭터는 베이크에서 제외했습니다. 관중은 실시간 조명을 받고, 참가자 아바타는 실시간 그림자도 만듭니다. 관중 전체의 실시간 그림자는 생성하지 않습니다.
- 금속·유리는 무대·복도·외부의 HDR로 반사합니다. 쇼케이스 유리는 원본처럼 얇고 굴절 없는 투명도와 Fresnel 반사를 사용합니다. 광선 26개는 반투명 메시로 재현하며 Blender의 볼륨 산란과 같은 계산은 아닙니다.
- AgX, 노출 0EV, sRGB 출력을 사용합니다. 실시간 조명·반사와 Blender EEVEE의 결과가 픽셀 단위로 같지는 않습니다.
- 현재 베이크는 커피숍 작업이 완료된 01:57:40 KST 원본 기준입니다. 검토용 낮 조명 대신 원본 `REF_NightArena`와 배경 강도 0.018을 사용합니다. 이후 Blender에서 바꾼 형상이나 고정 조명은 다시 내보내고 구워야 반영됩니다.
- 표면 UV를 보존하고 조명에는 별도 `uv3`를 사용합니다. 바닥 얼룩을 줄이도록 64샘플 베이크에 OIDN 노이즈 제거를 적용하고, 가는 나무 패널도 조명 텍셀을 확보하도록 UV를 배치했습니다.

## 검증과 범위

- Khronos glTF Validator: 오류 0, 경고 0. 검증기 자체가 Draco 데이터를 해제하지 못하는 정보 메시지는 남으며, 실제 디코딩은 Chromium에서 별도로 확인했습니다.
- 데스크톱 Chromium / RTX 3080 Ti: GLB 로드, 96개 관중 프리미티브의 동작 변화, 30초 음원 재생, 광장부터 무대 앞까지의 이동을 확인했습니다.
- 무대 절차형 표면 3종과 외벽·지붕 10종, 커피숍 표면 5종을 이미지로 변환했습니다. 표면 이미지는 GLB에 내장하고, 라이트맵 7개와 반사 HDR 3개는 별도로 제공합니다. 삼각형 수는 5,808,498개이며 단순화하지 않았습니다.
- Blender 원본을 저장·수정하지 않고 별도 스냅샷에서 내보냈습니다. 숨겨둔 복제본과 이전 무대, Blender 전용 볼륨 상자는 제외했습니다.
- 같은 카메라에서 관중석/무대 밝기를 비교하고 고정 조명의 중복 합산이 없음을 검사했습니다. 광장의 얇은 면에서 발생했던 검은 라이트맵 띠도 수정·확인했습니다.
- 390px 폭에서 버튼 배치를 확인했습니다. 실제 모바일 기기 성능, Safari/Firefox, 인터넷 회선에서의 로딩 시간은 검증하지 않았습니다. 모델 용량과 삼각형 수가 커 데스크톱 GPU 사용을 권장합니다.
- 기존 TPS·Space 점프·3인 WebRTC 접속과 참가자 간 위치·점프 높이 전달을 검사했습니다. 외부 호스팅 배포와 서로 다른 인터넷망에서의 접속은 시험하지 않았습니다. PeerJS 서비스 및 네트워크 조건에 대한 기존 의존성은 유지됩니다.

라이트맵과 완성된 매장 추가로 초기 다운로드와 GPU 메모리 사용량이 늘었습니다. 작은 조명 UV 사이의 번짐을 막기 위해 라이트맵의 mipmap을 끕니다. 원거리 작은 면의 반짝임이 남을 수 있습니다. 이 조명·유리 셰이더는 데스크톱 GPU를 대상으로 검증했으며 실제 모바일 성능 최적화는 포함하지 않았습니다. 정확한 파일 크기와 해시는 `web-export/delivery-manifest.json`에 기록됩니다.

환호음은 출처 제공자가 AI 생성·CC0로 표시한 효과음을 편집한 것이며 실제 결승전 녹음이 아닙니다.

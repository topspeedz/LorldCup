# Barclays Center · WORLDS 2026

**2026-11-12 웹 내보내기 갱신:** 재질·텍스처를 내장한 GLB와 관중 동작·환호음 실행 파일이 `web/`에 있습니다. 현재 파일 구성, 실행 방법과 검증 범위는 [웹 GLB 안내](web/README.md)를 확인하세요. 아래 제작 기록의 초기 모델 수치와 정적 관중 설명은 이전 버전 기준입니다.

`start.cmd`를 실행한 뒤 **http://127.0.0.1:8766/** 에서 체험합니다. 이 PC의 Python과 웹브라우저를 사용합니다. 인터넷 연결 없이 실행할 수 있으며 로컬 PC에서만 서버에 접속할 수 있습니다.

## 조작

- **직접 걸어 들어가기** 클릭 → 마우스로 시선 변경
- **WASD / 방향키** 캐릭터 이동 (3인칭 TPS), **Space** 점프, **Shift** 빠르게 걷기
- **Esc** 메뉴, **R** 광장으로 복귀
- 메뉴의 **외부 광장 / 입구 로비 / 무대 앞** 버튼으로 바로 이동
- 마우스 잠금을 지원하지 않으면 화면 드래그로 시선 변경

주 동선은 광장 → 서쪽 캐노피 → 개방된 정문 → 로비 → 101 진입로 → 내리막 통로 → 경기장 바닥 → 무대 계단입니다. 같은 길로 돌아나올 수 있습니다.

## 파일

- `barclays-worlds-2026.blend`: Blender 원본, 재질·텍스트·조명·3개 카메라 포함
- `web/arena.glb`: Blender MCP에서 생성하고 내보낸 웹용 모델
- `web/index.html`, `web/main.js`: WASD 이동, 바닥 추적, 벽 충돌, 좌석 통행 제한
- `renders/interior.png`, `renders/exterior.png`: Blender 렌더
- `build_scene.py`, `refine_scene.py`, `finish_scene.py`: Blender 내에서 순서대로 실행한 제작 스크립트. 재실행은 별도 새 장면을 만들므로 기존 결과를 대체하려면 장면 선택을 먼저 확인해야 합니다.
- `verification.json`: 이번 실행에서 확인한 검사 결과
- `web/vendor/`: 이 작업공간에서 이미 사용 중인 Three.js 0.170.0과 GLTFLoader, 라이선스

## 구현 범위

녹슨 강판 3단 외장, 타원형 오큘러스와 LED, 유리 외벽과 멀리언, 벤치·볼라드·이벤트 배너, 입구 게이트, 로비 조명, 매점·카운터·메뉴 보드, 지하 경기장, 하단/상단 관중석, 구역 번호, 통로 난간, 스위트 유리, LED 리본, 지붕 트러스·캣워크·스피커를 모델링했습니다.

파랑·흰색 원형 무대에는 동심원 계단과 LED, 5명씩 두 줄의 선수석, 모니터·키보드·마우스패드·PC·의자, 4면 대형 화면과 천장 매달림 구조가 있습니다. 19,384개 좌석과 12,392개 단순화된 관중 표현을 포함합니다. 관중과 장비는 정적 모델입니다.

## 기준과 한계

사용자가 모은 Barclays 사진과 제공한 행사 사진만 시각 참고자료로 사용했습니다. 사용자가 선택한 파랑·흰색 원형 무대에 WORLDS 2026 표기를 적용했습니다. 여러 행사 사진을 참고한 공간 재현이며 **실제 2026 결승전의 공식 배치나 개최 장소를 확인한 모델이 아닙니다.** 선수·팀·우승 결과는 지정하지 않았습니다.

건물 치수와 보이지 않는 연결 통로는 사진 비례를 바탕으로 만든 근사입니다. 실제 건축 도면·측량에 따른 디지털 트윈이나 사진측량 결과가 아닙니다. 외벽·주요 기둥·게이트·주요 장비는 충돌을 검사하고 좌석은 구역 단위로 통행을 제한합니다. 모든 작은 소품에 개별 충돌을 적용하지는 않았습니다. 상단 관중석으로 이어지는 전체 수직 동선과 화장실·서비스실 등 사진에 없는 공간은 구현하지 않았습니다.

마우스·키보드 기반 데스크톱 브라우저에서 검증했습니다. 터치 방향 버튼은 제공하지만 실제 모바일 기기에서 성능과 조작을 검증하지 않았습니다. GLB는 약 123 MB이며 GPU 환경에 따라 초기 로딩과 프레임 속도가 달라집니다. 실시간 경기 영상과 음향은 포함하지 않습니다.

## 3인칭 TPS와 WebRTC 함께 접속

`start.cmd`를 실행하면 임시 캐릭터를 뒤에서 따라가는 TPS 시점으로 체험할 수 있습니다. 마우스로 카메라를 회전하고 WASD로 시점 기준 이동합니다. 기존 바닥 추적·벽 충돌·빠른 이동·위치 이동 버튼을 유지합니다. 카메라와 충돌 대상 사이에 장애물이 있으면 카메라 거리를 줄입니다.

1. 메뉴에서 **방 만들기**를 누릅니다.
2. 표시된 16자리 방 코드를 상대에게 전달합니다.
3. 상대는 같은 웹 공간에서 코드를 입력하고 **입장**을 누릅니다.
4. Esc로 메뉴를 열고 **나가기**로 연결을 종료합니다.

캐릭터 위치와 방향을 초당 최대 10회 WebRTC DataChannel로 보냅니다. 방장 브라우저가 참가자의 위치를 모아 전달하므로 방장이 나가면 방 연결이 끝납니다. 방장 포함 최대 16개의 연결 슬롯을 허용하지만 실제 권장 인원이나 최대 부하는 아직 측정하지 않았습니다. 방 코드를 아는 사람은 입장할 수 있습니다. 로그인·음성·채팅·방 영구 저장은 포함하지 않습니다.

PeerJS 1.5.5를 로컬 vendor에 포함했으며 무료 PeerJS Cloud로 최초 연결 정보를 교환하고 Google STUN으로 직접 연결을 시도합니다. 유료 서비스나 TURN 서버는 설정하지 않았습니다. 외부 서비스 또는 네트워크 조건에 따라 연결이 실패할 수 있으며, 회사망·일부 모바일망에서는 TURN이 필요할 수 있습니다. 네트워크 오류가 나도 혼자 공간을 둘러볼 수 있습니다.

현재 실행 주소는 이 PC에서만 열리는 localhost입니다. 다른 기기에서 접속하려면 `web/` 전체를 정적 HTTPS 호스팅에 올려 같은 URL을 공유해야 합니다. 방 코드는 웹사이트 주소를 대신하지 않습니다. 외부 배포는 아직 수행하지 않았습니다. 웹 모델은 기존 arena.glb를 사용하며 Blender 원본을 다시 내보내거나 변경하지 않았습니다.

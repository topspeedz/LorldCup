# Barclays WORLDS 2026 — 레퍼런스 기반 경기장 재구성

2026-11-12. `Final Arena.png`의 정면 디자인과 사용자 승인 사항인 팀당 5석을 기준으로, 나머지 Arena 폴더 이미지를 측면·후면·상부 구조 참고로 사용했습니다.

작업 파일: `../barclays-worlds-2026.blend`  
작업 전 백업: `../before-reference-match-20261112.blend`  
Blender 장면: `Barclays • WORLDS 2026`  
새 구성: `ReferenceMatch` 컬렉션

| 구성 | 반영 내용 |
| --- | --- |
| 팀별 색상 | GEN.G 금색, BLG 청록·분홍색의 무대·전광판·관중석 리본 |
| 무대 | 어두운 원형 반사 데크, 중앙 트로피와 돌출 런웨이, 연결 경사면 |
| 배경 | 중앙 계단과 GRAND FINAL 벽체, 좌우 LED 패널과 비대칭 날개 구조 |
| 선수석 | 양 팀 5석씩, 기존 장비 27개 메시 그룹 재사용, 착석 선수 10명과 팀 유니폼 |
| 전광판 | 네 면 LED 화면, 프레임·하부 격자·서비스 데크·현수 구조 |
| 조명 | 팀별 스포트라이트, 볼륨 산란, 배경·관중석 워시, 트로피 조명, 반사와 블룸 |
| 관중 | 기존 캐릭터 관중 12,392명 유지, 응원봉 6,197개 배치 |
| 후면 | 벽체 두께, 지지대와 받침, 장비 케이스·케이블 |

전광판과 배경·책상 LED에는 제공 이미지에서 해당 그래픽 영역을 원근 보정해 사용했습니다. 경기장 전체는 실제 메시로 구성했으며, 무대 배경 전체를 한 장의 이미지로 대체하지 않았습니다. 주요 이미지 4개는 Blender 파일에 패킹했습니다.

기존 무대·장비 77개 오브젝트는 `ReferenceMatch_PreviousStage` 컬렉션에 보관되어 있습니다. 새 무대와 중복되지 않도록 이 컬렉션의 표시와 렌더만 꺼 두었습니다. 기존 경기장 건물·관중석 형상은 유지했습니다.

검증 결과는 `final-validation.json`에 오브젝트별로 기록했습니다. 새 컬렉션의 메시 358개를 검사했으며, 닫힌 구조 메시 142개는 원본과 모디파이어 적용 결과 모두 비매니폴드 경계가 없습니다. 나머지 216개는 LED 그래픽·로고·유니폼의 의도된 열린 표면입니다. 비정상 좌표·UV, 잘못된 재질 인덱스, 퇴화 면, 일관되지 않은 면 연결은 발견되지 않았습니다. 서로 다른 오브젝트 사이의 모든 교차를 자동 검사한 것은 아닙니다.

저장 시 기본 카메라는 `REF_Camera_Front`입니다. `render-views.py`로 네 방향 검토 렌더를 다시 만들 수 있습니다. `build-stage.py`, `equipment-players.py`, `lighting-look.py`, `refine-look.py`, `final-polish.py`는 제작 과정의 일회성 스크립트이므로 완성 장면에서 다시 실행하지 마세요. 이후 MCP로 적용한 치수·조명·카메라 조정은 저장된 Blender 파일이 최종본입니다.

2D 참고 이미지의 시점별 차이는 승인된 정면과 5석 기준으로 정리했습니다. 실측 자료 없이 모델링했으므로 모든 치수와 픽셀이 원본 이미지와 일치하는 것은 아닙니다. 선수와 관중은 스타일화된 캐릭터이며, 개인의 실사 얼굴을 복제하지 않았습니다.

이 결과는 Blender 데스크톱 렌더용입니다. 게임 엔진 내 성능·드로콜·GPU 시간, 모바일 셰이더, LOD0–3, 애니메이션 및 전체 동선 충돌 검사는 수행하지 않았습니다. EEVEE의 화면 공간 반사는 시점에 따라 달라질 수 있습니다.

후속 작업: 입구 통로 수정과 관중 동작·환호음은 [관중 애니메이션 보고서](../crowd-animation/README.md)에 기록했습니다. 위 수치는 무대 재구성 완료 당시의 측정입니다.

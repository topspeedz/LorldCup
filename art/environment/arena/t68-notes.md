# T68 검토안

자료 등급 C: 사용자 화면 한 장과 T63의 런타임 진단, 기존 제작 스크립트의 실측 좌표를 함께 사용했다.

| 항목 | 값 |
| --- | --- |
| 용도·거리 | 데스크톱 경기장 환경, 관중석·입구에서 약 1~15 m |
| 형태·재질 | 기존 콘크리트, 금속, 의자, 전광판 재사용; 움직이는 부분 없음 |
| 예산 | 5,866,000 삼각형, 939 프리미티브, 125 재질, 이미지 62장·최대 2048 px, GLB 120,200 KB |
| 수정 대상 | 스위트석 바닥의 안쪽 돌출부, 아래 전광판 64면, 입구 인접 계단의 의자·팔걸이·받침, 입구 연결 발판과 분기점 난간 |
| 연동 | 기존 노드 이름·좌표계·재질과 관중 속성 유지; T63b가 관중 숨김·좌석 선택·런타임 충돌 처리 |
| 검증 | `t68-check.py`의 실제 형상 검사, 기존 `arena-v2.spec.mjs`, GLB 노드 차이·예산 검사 |

## 사실과 제안

- 실제 머리 위 판은 `Suites_floor__concrete`다. 원래 높이는 Blender Z=1.0~1.3 m이며, 안쪽 타원 반경은 56×41 m다. 검사점 (0, −44.4, 0.7) 위에 이 판이 걸린다.
- 제안은 안쪽 돌출부 걷어 내기다. 안쪽 반경을 60.8×45.8 m로 물리고, 외곽 62×47 m와 기둥 받침 띠는 유지한다.
- 아래 전광판 `REF_RibbonProgram_0_*`와 그 글자를 남은 바닥 가장자리(반경 60.6×45.6 m)로 물린다. 높이는 그대로다. 위쪽 전광판과 2층 바닥도 그대로다.
- 입구에 가까운 두 방사형 계단(7π/8, 9π/8)의 입구 쪽 한 열씩, 각 23개 의자를 제거하는 검토안이다. 의자 46개의 방석·등받이·팔걸이와 바로 아래 받침 끝을 함께 처리한다.
- 양쪽 연결 발판은 기존 `Walk_Tier0__concrete`에 붙인다. 폭 1.4 m, 기존 단차 0.43 m이며, 경사로 x=−59 지점에서 분기한다. 분기점의 기존 난간 일부에 통과 개구부가 필요하다.
- 낮은 난간 두 메시의 서쪽 개구부도 양옆 발판까지 연다(로컬 Y=±4.8 m). 새 발판을 가로막는 부분만 처리한다.
- 그림은 T31의 CPU Cycles 방식으로 같은 카메라·조명·해상도로 찍는다. 형상 비교를 위해 양쪽 모두 관중을 숨긴다. 런타임 최종 아트 검증을 대신하지 않는다.
- 라이트맵은 굽지 않는다. 코디네이터 메시지 `msg_1e3b79f0436b`에 따라 T75가 통합해서 굽는다. 필요한 아틀라스는 발판·통로 바닥 `bowl`, 후퇴한 스위트석 바닥 `interior`, 이동한 전광판 `stage`이며, 제거한 의자의 남은 면 UV는 보존한다.

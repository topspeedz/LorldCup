# UI 디자인 토큰

- 읽는 시점: 화면 명세(`docs/live/graphicmodel/ui/<대상>.md`)를 쓰거나 읽을 때, `web/ui/tokens.css`를 만들거나 고칠 때, 아트 대조 때
- 역할과 소유 범위: 화면 UI 전체(입장·로딩, 팀·캐릭터 선택, 티켓, HUD·조작 막대, 감정표현 메뉴, 좌석, Full Mode, 방 초대)가 쓰는 색, 글꼴, 간격, 모서리, 판, 움직임, 겹침 순서의 값
- 소유 에이전트: `ui-designer`
- 마지막으로 갱신한 phase: 2026-11-13-ux-motion-rooms (T60: 새 토큰 없음, 두 토큰 쓰는 곳 없음 표시)

## 규칙

- 현재 상태만 담는다. 날짜가 붙은 경과, 대체된 옛 내용, 백로그 번호 나열을 넣지 않는다.
- 30KB를 넘으면 주제별로 나눈다.
- 갱신은 소유 에이전트의 Task로 계획에 넣는다. 다른 팀은 읽기만 한다.
- 화면 명세와 시안의 모든 값은 이 표의 토큰 이름으로만 부른다. 표에 없는 값이 필요하면 화면 명세에 쓰지 말고 이 표에 먼저 더한다.
- CSS 변수 이름은 토큰 이름 앞에 `--`를 붙인 것이다(`color-accent` → `--color-accent`). 값은 이 표 그대로 옮긴다.
- 강조색은 `color-accent` 하나다. 주된 조작 하나, 선택된 것, 키보드 초점에만 쓴다. 상태는 색만으로 알리지 않고 글자나 모양을 함께 둔다.
- 아트 디렉션에 없는 색이 필요하면 만들지 않고 `graphic-leader`에게 올린다(아래 `## 결정 필요`).
- 근원 칸의 말: "아트 디렉션 화면 UI"는 `docs/live/graphicmodel/art-direction.md`의 `## 화면 UI` 표, "지금 앱"은 이 표 이전 `web/index.html`에 있던 값, "WCAG"는 WCAG 2.2의 해당 기준, "출발값"은 실측 전 시작값이다.

### 움직임

`prefers-reduced-motion: reduce`에서는 모든 `motion-*` 시간이 `0ms`이고, 나타남·사라짐은 불투명도만 바로 바뀐다(옮겨 가는 움직임 없음).

| 토큰 | 값 | 쓰는 곳 | 근원 |
| --- | --- | --- | --- |
| `motion-fast` | `90ms` | 누름 반응, 올림 바탕 바뀜 | 출발값 |
| `motion-base` | `160ms` | 메뉴·판 나타남과 사라짐 | 출발값 |
| `motion-slow` | `280ms` | 화면 전환(로딩 → 입장, 입장 → 걷기) | 출발값 |
| `motion-hide-delay` | `2500ms` | Full Mode·앉기에서 손을 놓은 뒤 영상 위 요소가 흐려지기까지 | 출발값(UX 명세가 다르게 정하면 그 값) |
| `ease-out` | `cubic-bezier(0.2, 0, 0, 1)` | 나타남 | 출발값 |
| `ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 사라짐 | 출발값 |

## 접근성 하한

| 항목 | 하한 | 출처 |
| --- | --- | --- |
| 본문 글자 대비 | 4.5:1 (큰 글자 3:1) | WCAG 2.2 1.4.3 |
| 버튼 테두리, 아이콘, 초점 표시 대비 | 3:1 | WCAG 2.2 1.4.11 |
| 누르는 대상 크기 | 24×24 CSS px 이상 | WCAG 2.2 2.5.8 |
| 색만으로 알리지 않음 | 모양이나 글자를 함께 | WCAG 2.2 1.4.1 |

위 색 토큰의 글자 조합은 판 위에서 모두 4.5:1 이상이다. `color-border-subtle`은 꾸밈 선이라 경계 표시로 쓰지 않는다.

## 토큰이 아닌 값

- 팀 색(팀·캐릭터 선택의 견본, 티켓 카드 바탕)은 팀 데이터의 `color`·`accent`를 그대로 쓴다. 그 위 글자는 대비를 화면 명세가 팀마다 확인한다.

## 결정 필요

- 오류·실패 색: 아트 디렉션에 없다. 지금은 실패를 `color-warning`과 글자로만 알린다. 실패 전용 색이 필요하면 `graphic-leader`가 아트 디렉션 `## 화면 UI`에 더한다.

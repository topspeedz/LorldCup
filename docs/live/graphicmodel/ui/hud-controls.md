# HUD·조작 막대 화면 명세

- 읽는 시점: 경기장 안에 늘 떠 있는 요소(오른쪽 위 키 힌트, 오른쪽 설정 묶음, 다음 할 일 줄, 오른쪽 아래 행동 버튼, 터치 방향 버튼, 알림)를 만들거나 고칠 때. 감정표현 메뉴·좌석·Full Mode·방 초대·입장 명세가 이 문서의 「공용 자리」를 가리킨다.
- 역할과 소유 범위: 경기장 안에서 늘 떠 있는 화면 요소의 자리, 크기, 위계, 겹침, 상태별 모양. 흐름과 조작은 UX 명세가 정본이다.
- 소유 에이전트: `ui-designer`
- 마지막으로 갱신한 phase: 2026-11-13-ux-motion-rooms (T60 마우스 우선 개정)
- 입력: UX 명세 `docs/live/product/ux/hud-controls.md`(T59 개정, H-D1·H-D2 채택), 토큰 `docs/live/graphicmodel/ui/tokens.md`, 아트 디렉션 `## 화면 UI`

## 규칙

- 현재 상태만 담는다. 30KB를 넘으면 나눈다. 갱신은 소유 에이전트의 Task로 한다.
- 모든 값은 토큰 이름으로 부른다. 토큰을 더한 식(예: `space-5` × 8)은 쓰지만 새 숫자는 쓰지 않는다.
- 문구는 UX 명세 `## 6. 문자열`이 정본이다. 이 문서는 문구를 옮겨 적지 않고 자리만 정한다.

## 원칙 (T60)

- **마우스가 기본이다.** 커서는 늘 보이고(포인터를 잠그지 않음, UX H-D1), 모든 버튼은 늘 같은 자리에 보인다(예외: 아래 「'늘 보인다'의 예외」). 키를 눌러야 나타나는 요소, 메뉴 상태, "다시 걷기"가 없다. Esc는 화면 요소를 열거나 숨기지 않는다.
- **상자를 줄인다.** 경기장 안의 상시 상자는 키 힌트 1, 설정 묶음 1, 다음 할 일 1(티켓 전), 행동 버튼 2~3이다. 설정 묶음 안의 조작은 테두리 없는 줄 버튼(`## 컴포넌트`의 줄 버튼)이라 상자로 보이지 않는다.
- **없앤 요소:** 이동 버튼 `#quick`, 관중 소리 `#crowd-sound`, 위치 이름 `#zone`, 상태 글자 `#hud-state`, 조준점 `#cross`, 아래 가운데 키 안내 줄, 왼쪽 아래 조작 막대(자리를 설정 묶음으로 옮김), 터치 ☰ 메뉴 `#menu-open`, "다시 걷기" `#walk-resume`, 경기장 안의 머리(`header`). ID의 처리는 아키텍처 고정 ID 표(T61)가 정한다.
- **강조색은 상태마다 하나.** 걷기에는 강조 버튼이 없다(다음 할 일 줄의 왼쪽 선만 강조색). 좌석 가까이면 "앉기", 앉으면 "Full Mode", 첫 페이지는 "들어가기", Full Mode는 "Full Mode 닫기".

## 공용 자리

| 이름 | 정의 |
| --- | --- |
| 가장자리 | 데스크톱 `space-5`. 터치(`body.touch`)나 폭 650px 이하는 `max(space-4, safe-inset)` |
| 버튼 높이 | 데스크톱: 글자 한 줄(`font-size-sm` × `line-height-body`) + 위아래 `space-2`, 최소 `size-target-min`. 터치: `size-target-touch` |
| 오른쪽 위 열 | 위·오른쪽 가장자리에서 아래로 쌓는 열, 너비 `hud-col-width`, 사이 `space-2`. 위에서부터 키 힌트(데스크톱만) → 설정 묶음 → (잠깐) 복사 안내 |
| 왼쪽 위 | 다음 할 일 줄(티켓 전만). 터치에서는 오른쪽 위 열과 `space-4` 이상 띄우고 넘치면 두 줄로 접는다 |
| 오른쪽 아래 | 행동 버튼 묶음 `#dock`(데스크톱). 터치는 방향 버튼 `#touch` |
| 왼쪽 아래 | 터치의 행동 버튼 묶음(세로 2칸) |
| 아래 가운데 | 좌석 가까이의 "앉기" 버튼(`seat.md`). 터치는 방향 버튼 위 `space-3` |
| 위 가운데 | 알림(아래 「알림(공용 정본)」) |

- 화면 가운데와 스크린 영상에는 상시 요소를 두지 않는다. 앉은 화면(1280×720)에서 영상은 x 232~1048, y 34~600이고, 오른쪽 위 열(x 1064~1256)과 오른쪽 아래 행동 버튼(y 660 아래)은 영상 밖이다(시안 `d-seated.png`, 검사 `checks.json` "off the video"). 스크린 영상 위에 놓이는 앱 DOM은 0개다. 잠깐 뜨는 복사 안내(`room-invite.md`, 열 너비 안에서 접음)와 알림(아래 「알림」의 앉기 자리)도 영상 밖이다(법무 LG-H-4·LG-M-15, YT-05).
- **'늘 보인다'의 예외.** 걷는 동안 시점이 움직여 스크린 영상(플레이어 사각형)이 상시 요소의 자리에 오면, 그 요소는 지금의 숨김 장치(`web/screen-video.js` 겹침 처리)를 따른다: 행동 버튼 묶음·감정표현 메뉴처럼 비켜나는 요소는 영상 바로 위·아래·오른쪽·왼쪽으로 옮겨지고, 들어갈 자리가 없거나 그 밖의 요소(키 힌트, 설정 묶음, 복사 안내, 알림)는 겹치는 동안 숨는다. 영상이 비켜나면 제자리에 다시 보인다. 앉기·Full Mode에서는 배치상 겹치지 않으므로 이 예외가 일어나지 않는다.

## 작은 창·모바일

- 터치(`body.touch`, 390×844 기준): 키 힌트 상자가 없다. 오른쪽 위 열은 설정 묶음 하나(너비 `hud-col-width` 터치 값, 줄 버튼 높이 `size-target-touch`). 다음 할 일 줄은 왼쪽 위가 아니라 **왼쪽 아래**, 남은 시간 줄(`entry-loading.md`) 바로 위 `space-2`(대기가 없으면 남은 시간 줄의 자리)에 두고 넘치면 두 줄. 왼쪽 위는 걸린 스크린(0,0–195,170)과 겹친다(LG-H-4b, T60c).
- 방향 버튼 `#touch`: 오른쪽 아래, 칸 `size-target-touch` × 3열 2줄(위 줄은 가운데 한 칸), 사이 `space-2`. 앉아도 남는다(누르면 일어난다).
- 행동 버튼 묶음: 왼쪽 아래, 세로 2칸("감정표현", "Full Mode"; 앉으면 "감정표현", "일어나기", "Full Mode"), 버튼 `size-target-touch`.
- 좌석 가까이의 "앉기": 방향 버튼 위 `space-3`, 가로 가운데.
- 터치가 아닌 좁은 창(폭 650px 이하, 키보드 있음): 키 힌트 상자를 남기되 이동·점프 줄을 빼고 Shift·Alt·F(좌석 가까이면 E)만.
- ☰ 메뉴는 없다. 모든 조작이 늘 보인다(예외: 위 「'늘 보인다'의 예외」).

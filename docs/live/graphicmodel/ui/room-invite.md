# 방 초대 화면 명세

- 읽는 시점: 설정 묶음의 '같이 보기' 줄, 복사 안내, 사람 수 줄, 자동 연결 고지의 자리, 초대 링크로 온 사람의 들어가기 화면을 만들거나 고칠 때
- 역할과 소유 범위: 위 요소의 자리, 크기, 위계, 겹침, 상태별 모양. 흐름과 문구는 UX 명세 `docs/live/product/ux/room-invite.md`, 오른쪽 위 열과 설정 묶음의 틀은 `hud-controls.md`, 첫 페이지는 `entry-loading.md`가 소유한다
- 소유 에이전트: `ui-designer`
- 마지막으로 갱신한 phase: 2026-11-13-ux-motion-rooms (T60 마우스 우선 개정)
- 입력: UX 명세 `docs/live/product/ux/room-invite.md`(T59 개정), 토큰 `tokens.md`, 사용자 원문(`_workspace/qa/2026-11-13-ux-motion-rooms/spec/user-feedback.md`): "링크는 복사가 됐는데 여기화면에 방번호에 넣어야되는줄알았어" / "같이 보기 버튼하나만있어도되겠네" / "혼자시청중도 없애야지"

## 규칙

- 값은 토큰 이름으로만 부른다. 문구는 UX 명세 `## 6. 문자열`이 정본이다.
- 떠 있는 방 패널은 없다. 방에 닿는 조작은 설정 묶음 안의 '같이 보기' 줄 하나다.

## 없앤 것

방 패널 상자(`#network`의 떠 있는 판), 방 번호 입력 `#room-code`, "이 방으로 옮기기" `#join-room`, `#host-room`, "방 나가기·다시 같이 보기" `#leave-room`, 방 상태 한 줄 `#hud-room`("방 01 · 혼자 시청 중"), 패널 안 두 번째 고지, 방장 글자. 방 번호 입력칸이 화면 어디에도 없으므로 복사한 링크를 넣을 자리로 오해할 칸이 없다.

## 작은 창·모바일

- 390×844: '같이 보기'는 설정 묶음(오른쪽 위) 안 그대로, 줄 높이 `size-target-touch`. 복사 안내는 묶음 아래 `space-2`, 데스크톱과 같이 묶음 너비(`hud-col-width` 터치 값) 안에서 줄을 접는다(시안 `m-copied.png`, `m-seated.png`).
- 휴대폰에 공유 창이 있으면 누른 순간 공유 창이 먼저 뜨고, 닫으면 복사 안내 한 줄(UX M12).

## 결정 필요

- 고지 자리: UX 명세는 "들어가기 바로 아래", T60 지시는 "입장 버튼 위"다. 이 명세는 버튼 위로 정했다(누르기 전에 읽히고, 390×844에서 버튼과 함께 첫 화면 안). `ux-designer`가 UX 문구 표의 자리 말을 맞춘다.
- 고지 문구와 "자세히" 안의 원문은 T62(법무) 판정 뒤 확정한다. 이 명세는 두 줄까지 들어가는 자리만 잡았다.

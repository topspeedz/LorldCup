## 컨셉과 판정 원칙

기존 경기장 안의 관중·선수와 같은 양식으로, 가벼운 야외 차림의 팬들이 어두운 밤에 응원하는 세계를 이어간다. 기준은 기존 인물의 비례와 디테일 밀도, 밤에도 읽히는 조형물 윤곽, 은은한 하늘 연출이다. 새 비례·재질 양식을 독립적으로 도입하지 않는다.

사용자 결정의 정본은 실행 브리프의 사용자 결정과 적용 절이다. 색·밝기·속도 등의 기본값은 설정값이며 사용자 화면 확인 때 바꾼다. 아래에서 '기존'은 이번 phase 변경 전 경기장과 관중·선수의 모습을 뜻한다. 아트 판정은 같은 카메라·환경 조명·톤 매핑의 런타임 비교 화면으로 하며, Blender 기본 화면만으로 승인하지 않는다.

## 팬 캐릭터

여자 2종·남자 2종, 총 4종이다. 헤어스타일과 인종에 변화를 주며 머리 모양·피부색·얼굴 표현으로 구분한다. 특정 인종과 성별별 외형 조합을 이 문서에서 새로 지정하지 않는다. 가벼운 야외 응원 차림으로 만들고, 머리와 몸의 비례·얼굴의 표현 수준·가장자리 처리·재질의 디테일 밀도는 기존 관중·선수와 나란히 보아 같은 세계로 읽히게 유지한다.

공용 뼈대와 기존 이동·응원 동작을 함께 사용할 수 있는 형태를 유지한다. 구체적인 뼈·클립·재질 이름과 규격은 자산 연동 규약을 따른다. 팀과 캐릭터를 함께 직접 선택하며, 선택한 모습은 같은 방의 다른 사람에게도 보인다.

GEN.G·BLG 유니폼은 옷 자체의 그림이다. 몸 위에 떠 있는 별도 옷 메시처럼 보이면 안 된다. 법무 앞 검토 전에는 로고 없는 팀 색을 쓰고, 검토 통과 뒤 기존 저지 그림을 사용한다. 새 로고나 소품은 이 기준의 요구가 아니다.

## 밤

현재보다 어두운 밤하늘에 별과 달이 보인다. 설계 기본값은 별 3000개와 은은한 반짝임, 달 고도 35°이며, 밝기는 사용자 화면 확인 때 조정한다. 달빛 기본색은 옅은 청백색으로 두되 새 색상 수치를 고정하지 않는다.

달빛 범위는 야외 조형물과 야외에서 움직이는 캐릭터다. 추가 손전등 없이 야외 조형물의 윤곽을 알아볼 수 있어야 하고 캐릭터의 달빛은 약하게 둔다. 어둡게 한다는 이유로 조형물 윤곽을 잃으면 통과가 아니다. 정적 면과 움직이는 대상의 달빛 방향은 자산 연동 규약의 단일 기준을 따른다. 실내 조명을 일괄 어둡게 바꾸는 요구로 확대하지 않는다.

## 바다

광장에서 건물 입구를 볼 때 등 뒤인 서쪽에, 지평선까지 끝없이 이어지는 바다가 보인다. 실제 3D 지형 여부보다 화면에서 깊이와 수평선이 읽히는 것이 기준이다. 바다 영역에는 캐릭터가 들어가지 못한다.

기본색은 어두운 청남색이다. 새 색상 수치를 고정하지 않고 밤하늘과 맞닿은 수평선과 바다 표면이 구분되는지 화면으로 판정한다. 색과 밝기는 설정값이며 사용자 화면 확인 때 바꾼다. 위치 좌표와 구현 규격은 자산 연동 규약을 따른다.

## 하늘 쇼

야외 관람장 하늘을 향한 사선 빛줄기는 3개다. 좌우 왕복을 계속하며 가끔 폭죽이 터진다. 설계 기본값은 왕복 8초, 각도 ±25°, 폭죽은 20~40초마다 1~3발이다. 빛줄기 수는 사용자 결정으로 고정하고 속도·각도·빈도·밝기는 설정값으로 두어 화면 확인 때 바꾼다.

색은 기존 무대 빛줄기의 색을 재사용한다. 폭죽도 해당 색을 기본 팔레트로 대조하며 새로운 팔레트를 고정하지 않는다. 투명도 기본값은 기존 무대 빛줄기 수준인 0.055로, 밤하늘에 은은하게 읽히게 한다. 밤의 어두운 분위기와 조형물 윤곽을 유지한 상태에서 움직이는 빛과 간헐적인 폭죽이 구분되는지 본다.

## 마네킹

2층 전체 관중을 1층 관중보다 단순한 마네킹으로 바꾼다. 기존 관중의 머리·몸통·팔 실루엣과 좌석별 색을 유지하고 세부 얼굴·손가락은 생략한다. 새 사람 양식을 만들지 않으며, 1층 관람 위치에서 단순화 전후의 차이가 거의 보이지 않아야 한다. 환호 구간에만 움직이고 그 밖에는 멈춘다.

'먼 관중'은 2층 전체와 보는 사람 기준 180도 반대편 관중석이다. 이는 낮은 텍스처를 적용하는 범위이며, 반대편의 모든 관중을 마네킹으로 교체한다는 뜻이 아니다. 2층 판별과 반대편 범위의 수치 기본값, 텍스처·삼각형 예산은 자산 연동 규약을 따른다. 마네킹은 낮은 텍스처 또는 단색으로 표현하되 기존 좌석별 색의 분포를 유지한다.

## 승인된 참조

기존 경기장 관중·선수의 양식과 기존 무대 빛줄기가 비교 기준이다. 새 캐릭터 시트나 결과물의 승인된 그림은 아직 없다. 제작 Task는 기존 대상과 새 대상의 런타임 조건 비교 그림을 제출하고, 아트 리뷰에서 위 표로 판정한다.

## 결정 필요

없음. 미지정 색·형태는 코디네이터가 허용한 위 기본값으로 진행한다. 세부 외형 조합은 이 문서에서 임의 확정하지 않으며 캐릭터 시트 단계에서 구체화한다.

## 화면 UI

화면 UI 전체는 기존 경기장의 차분한 밤 분위기를 잇는다. 짙은 청남색 바탕과 판 위에 청백색 글자를 놓고, 하늘색 하나로 주요 행동·선택·포커스를 드러낸다. 입장·로딩, 팀·캐릭터 선택, 티켓, HUD·조작 막대, 감정표현 메뉴, 좌석, Full Mode, 방 초대에 같은 기준을 적용한다. 아래 팔레트는 창구 위임으로 채택한 제작 출발값이다. 화면별 배치·상태·치수와 디자인 토큰은 UI 명세에서 구체화한다.

## 이펙트

이펙트는 기존 팬의 양식에 맞는 작고 명확한 응원 표식으로 표현한다. 박수 환호·하트·화내기·계란 던지기를 색과 형태 양쪽으로 구분한다. 밝기 위계는 영상의 주시성을 우선하고, 인물의 윤곽과 동작을 읽을 수 있는 상태에서 국소 효과가 보이도록 한다. 밤 경기장 전체를 밝히거나 지속적인 큰 발광으로 인물과 영상을 덮지 않는다. 아래 색은 창구 위임으로 채택한 제작 출발값이며, 큐·크기·지속·재질 구성은 이펙트 연출 명세가 구체화한다. 연동 규격과 예산은 [자산 연동 규약](../web-metaverse-develop/asset-contract.md)을 따른다.

# HUD·조작 막대 UX 명세

- 읽는 시점: 경기장 안에 늘 떠 있는 요소(오른쪽 위 키 힌트, 오른쪽 설정 묶음: 같이 보기·소리·음량, 다음 할 일 줄, 스크린 연결 안내)를 만들거나 고칠 때. UI 명세(`docs/live/graphicmodel/ui/hud-controls.md`), 아키텍처 고정 ID 표(T61), 화면 적용(T46b), UX 재걷기가 읽는다.
- 역할과 소유 범위: 경기장 안에서 늘 떠 있는 화면 요소의 흐름과 상태별 조작, 그리고 마우스 우선 조작 모델(H-D1·H-D2). 감정표현(`emote-menu.md`), 좌석(`seat.md`), Full Mode(`full-mode.md`), 방(`room-invite.md`), 첫 페이지·로딩(`entry-loading.md`)은 각자의 명세가 있고, 이 문서는 그것들을 화면에서 찾는 자리만 다룬다.
- 소유 에이전트: `ux-designer`
- 마지막으로 갱신한 phase: 2026-11-13-ux-motion-rooms (T59 마우스 우선 개정)

## 0. 이번 개정의 근거 (T59)

- 사용자 원문: "일단 모든것은 키보드가 기본이 아니고 Mouse로 UI를 설정할 수 있는 형태가 될 수 있을 정도로 초반 UI에서 직관적으로 알 수 있게 해줘. 그리고 너무 많은 사각박스로 인해서 헷갈리게하지말고 문구도 줄여줘. 외부 광장 입구로비 무대앞 이렇거 다 없애고. 관중소리 켜기 이런것도 다 없애 Default가 소리는 일단 다키는거고" / "커서풀림 이런것도 다 없애 뭐가 중요해 이게" / (#zone) "응없애." / "그리고 키안내도 그냥 우측상단에 조그맣게 박스로 띄워" / "오른쪽에 일단 설정관련된건 다 몰아, 볼륨조절도 넣을수있게 해주고," / "esc키에 따라 UI나오는것도 없애줘 esc키는 적합하지 않아. 그냥 아까처럼 우측상단에 키 별로 무슨기능인지 간단히 힌트로만있어면될거같아. 거기에 추가해야될것 감정표현 Alt와 동영상 Full mode F가 필요할것같네" / "Shift 달리기도 넣어주고"

## 2. 사용자 흐름

### 2.1 마우스 우선 조작 모델 (H-D1·H-D2)

```text
[들어가기] → [경기장: 커서 보임(잠그지 않음)]
   ├ 마우스 드래그(왼쪽 버튼 누르고 끌기) → 둘러보기. 놓으면 커서 그대로
   ├ 바닥 클릭 → 그 자리까지 걸어감(H-D2 추천). 좌석 표시 클릭 → 그 좌석까지 걸어가 앉음
   ├ 버튼 클릭 → 감정표현 메뉴 / Full Mode / 팀·캐릭터 / 같이 보기 / 소리 / 음량
   └ 키(보조) → WASD·Space·Shift·Alt·F·E (오른쪽 위 힌트에 적힌 것)
```

- 커서는 늘 보이고, 버튼은 늘 같은 자리에 있다. "다시 걷기", "화면을 눌러 다시 걷기", 메뉴 상태가 없다.
- 반응: 키 힌트 상자의 키는 눌린 순간 한 번 밝아진다(지금 동작 유지). 바닥 클릭은 누른 자리에 작은 표시가 잠깐 뜬다.

### 2.2 소리와 음량

```text
[들어가기 클릭] → [영상·관중 소리 켜짐(브라우저가 막으면: 아래)]
[오른쪽 묶음] → 소리 버튼(끄기 ↔ 켜기, 앞 음량 기억) · 음량 막대(영상과 관중 소리 함께)
```

- 브라우저가 소리 자동 재생을 막으면(들어가기 클릭이 사용자 동작이므로 드물다) 소리 버튼이 "소리 켜기"로 보이고 한 번 누르면 켜진다. 따로 안내 상자는 띄우지 않는다.

### 2.3 처음 온 사람

```text
[경기장 첫 그림] → [다음 할 일 "입구로 가서 티켓 받기" + 오른쪽 위 키 힌트] → [W를 누르거나 입구 쪽 바닥을 클릭] → 입구(ticket.md)
```

## 4. 수락 기준 제안

- 마우스만으로: 키를 하나도 쓰지 않고 들어가기 → 팀 고르기 → 좌석에 앉기 → Full Mode → 같이 보기 복사까지 간다(T59 걷기와 같은 길).
- 어느 그림에도 이동 버튼, 위치 이름, 상태 글자, "관중 소리 켜기", "Esc 커서 풀기", "다시 걷기"가 없다.
- 키 힌트 상자에 적힌 키는 모두 동작하고, 동작하는 키(E 말고)는 모두 적혀 있다.
- R 키가 없다: 키 힌트에 R 줄이 없고, R을 눌러도 아무 일도 없다(순간이동 없음).
- 들어간 직후 소리가 난다.
